# Legacy content

Everything else in this directory is preserved as-is from the old
`dnd5e_combat`-based engine (`dnd/` at the top-level workspace, since deleted —
Phase 6 of `design/05-migration-plan.md`), for historical context only.

**The numbers, charts, and prose here do NOT reflect the new `simharness_v2`
engine's actual output.** For the new engine's current, measured parity status
against these old-engine numbers (several documented gaps, some large), see
`../../../design/07-known-issues.md`.
